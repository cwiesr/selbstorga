Titel
Geräte-Sync
Dieselbe Passphrase auf allen Geräten = dieselben Daten. Alles wird vor dem Hochladen verschlüsselt (Ende-zu-Ende) – Server und Datenbank sehen nichts Lesbares. Wähl eine lange, einzigartige Passphrase; sie kann nicht wiederhergestellt werden.
Sicherung & Wiederherstellung
Sync läuft nur in der echten Web-Version (z.B. Vercel), nicht in der Chat-Vorschau. Die Passphrase wird lokal auf diesem Gerät gespeichert, damit der Abgleich automatisch passiert.
⚙ Einstellungen
🔒 PIN-Schutz
Sperrt die App mit einer 6–8-stelligen PIN. Nach 3 Std. wird sie erneut abgefragt. Der PIN wird nur als Hash gespeichert (nie im Klartext).
